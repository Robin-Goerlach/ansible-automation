# Roadmap

A milestone is complete only when its documented acceptance criteria pass.

## Milestone 1: Repository foundation — complete (`v0.1.0`)

Repository governance, bootstrap, safe inventory, validation, diagnostics, audit-first foundation role, manifests, CI, and acceptance tests.

## Milestone 2: Linux baseline — complete (`v0.2.0`)

Packages, access administration, guarded SSH, time, logging, firewall, updates, reboot policy, reports, and disposable-VM scenarios.

## Milestone 3: Web services — complete (`v0.3.0`)

Apache, Nginx, PHP, TLS certificate handling, virtual hosts, native configuration validation, file-level rollback, endpoint checks, reports, and isolated template acceptance.

## Milestone 4: Diagnostics — complete (`v0.4.0`)

CPU, memory, swap, disk, inodes, processes, services, packages, network, DNS, ports,
certificates, correlated summaries, and standardized sanitized bundles.

See [Milestone 4](docs/milestones/milestone-4.md).

## Milestone 5: Controlled remediation

Risk classification, preflight, diagnosis, backup, remediation, validation, reporting, and rollback contracts.

## Milestone 6: Databases and containers

MariaDB, PostgreSQL, Docker, Podman, local registry integration, backup, and restore.

## Milestone 7: Monitoring and security

Prometheus exporters, Grafana, Alertmanager, auditd, fail2ban, and security status collection.

## Milestone 8: Collection and execution environments

`sasd.operations`, Execution Environments, Molecule matrix, release automation, signatures, and AWX compatibility.
